# X Post Length Constraints (Nia Account)

**Last updated:** 2026-10-25

## Current Account Status
- Nia’s X account is on the **free tier** (no X Premium / Plus).
- Standard posts are limited to approximately **280 characters**.
- Longer posts trigger “Upgrade to Plus to write longer posts and Articles.”

## Mandatory Rule for All Automated / Generated Content

When generating English posts intended for direct publishing on X (Insight, Practical Builder, Opinion, short Thread posts):

1. **Default target: ≤ 280 characters** (strictly usable on free tier).
2. Hard upper bound requested by Nia: **≤ 300 characters**.
3. Always produce a version that can be copied and posted immediately without hitting the length limit or Upgrade prompt.
4. If a longer version is useful for reference or for future Premium use, provide it **separately** and clearly label it as “Long version (requires Plus)”.
5. Prefer tight, high-signal writing. Cut filler. Keep the core insight, one concrete observation, and a clean close.

## Recommended Post Types under Free Limit
- Single Insight post
- Practical tip post
- Short Opinion / Discussion opener
- Thread posts: each individual post in the thread must also stay ≤ 280 characters

## Enforcement for Future Automation
Any content generation skill, workflow, or daily intelligence task that outputs “ready-to-publish English posts” for Nia’s X account **must** apply these length constraints by default.

Do not output long-form English posts as the primary deliverable unless explicitly requested for Articles or Premium use.
