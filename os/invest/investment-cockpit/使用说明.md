# 投资驾驶舱使用说明

## 每天自动运行的任务
系统每天自动执行三次关键任务：

1. 9:15 早盘任务
- 更新价格数据
- 发送推荐股票到飞书（早盘推荐）

2. 12:30 午盘任务
- 分析当日表现
- 发送操作建议到飞书（午盘决策）

3. 晚上自动任务
- 生成完整日报
- 汇总相关新闻
- 发送飞书通知（晚盘日报）
- 同步飞书多维表格并发送同步完成通知

## 飞书通知内容
系统会自动发送以下四类飞书通知：

1. 早盘推荐
- 内容：推荐股票
- 目的：开盘后快速关注当日优先标的

2. 午盘决策
- 内容：操作建议
- 目的：根据盘中表现调整策略

3. 晚盘日报
- 内容：持仓概况
- 目的：收盘后统一复盘和次日准备

4. 多维表格同步完成通知
- 内容：同步状态与结果
- 目的：确认当日数据已入库并可追踪

## Obsidian 文档说明
以下是 Obsidian 中的核心目录与用途：

1. `00_总览/日报总览.md`
- 每日报告索引
- 用于统一查看历史日报入口

2. `01_每日简报/`
- 每天的 AI 产业链投资日报
- 记录当日信号、建议与重点事件

3. `05_交易复盘/`
- 周度复盘报告
- 用于汇总阶段表现与策略修正

## 飞书多维表格
- 链接：https://feishu.cn/base/WWfIbvCw7agzDjsCXIUcjzZnnlh
- 包含内容：持仓表、交易记录、策略信号、观察池
- 同步机制：每天晚上自动同步并通知

## 手动测试命令
如需手动验证关键流程，可在项目根目录执行：

1. 测试今日报告
```bash
python3 scripts/test_today_report.py
```

2. 测试飞书通知
```bash
python3 scripts/test_feishu_notify.py
```

3. 查看持仓
```bash
python3 scripts/view_portfolio.py
```

4. 更新价格
```bash
python3 scripts/update_positions_price.py
```
