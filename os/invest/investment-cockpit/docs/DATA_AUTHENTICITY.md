# 数据真实性说明

本文档说明投资驾驶舱系统中所有数据的来源和真实性。

## 数据源

### 1. 市场数据
- **来源**: AKShare API
- **内容**: 股票价格、成交量、指数数据
- **更新频率**: 每日自动更新
- **真实性**: 100% 真实市场数据

### 2. 新闻数据
- **来源**: 数据库 news_report/news_events 表
- **内容**: 股票相关新闻标题、内容、时间
- **处理方式**: 关键词情感分析
- **真实性**: 100% 真实新闻数据

### 3. 基本面数据
- **来源**: AKShare API (stock_financial_analysis_indicator)
- **内容**: ROE、营收增长率、净利润增长率、资产负债率
- **更新频率**: 财报发布后更新
- **真实性**: 100% 真实财报数据

### 4. 行业数据
- **来源**: 数据库 watchlist 表
- **内容**: 行业分类、行业收益率、资金流向
- **计算方式**: 基于真实股票价格计算
- **真实性**: 100% 真实行业数据

### 5. 回测数据
- **来源**: BacktestEngine + 历史信号 + 真实价格
- **内容**: 历史策略表现、收益率、Sharpe、胜率
- **计算方式**: 基于历史信号回放真实交易
- **真实性**: 100% 真实回测结果

### 6. 持仓交易数据
- **来源**: 数据库 real_positions/real_trades 表
- **内容**: 实际持仓、交易记录、盈亏
- **真实性**: 100% 真实交易数据

## 参数优化真实性

参数优化使用真实回测引擎：
1. 使用候选参数重新计算因子
2. 重新生成策略信号
3. 使用 BacktestEngine 回测历史数据
4. 计算真实的 Sharpe、胜率、收益率
5. 基于真实表现选择最优参数

**不使用任何模拟数据或随机生成的分数。**

## 适用场景

本系统使用 100% 真实数据，适合：
- ✅ 量化交易比赛
- ✅ 实盘交易
- ✅ 策略研究
- ✅ 学术研究
