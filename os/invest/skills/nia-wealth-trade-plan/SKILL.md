# 条件化交易决策

先取得 holdings 验证、诊断证据、risk 结果与用户已确认限额。数据、规则或风险为 unknown/block 时只输出待验证预案，`quantity=null`、`executable=false`；不能为了填满“今日三项”强行交易。

每项计划明确：证券代码/份额类别、账户别名、方向、理由与反证、触发条件、失效条件、有效时段、价格/净值口径、目标权重区间、最大可用资金、费用与滑点假设、拟议数量或金额、交易后风险、复核时间和状态 `proposed`。

触发条件须能观察和复核，区分价格条件、基本面条件、组合再平衡条件。没有现价时可以写“价格进入经证据确定的区间后复核”，不能编一个数值。止损价是计划条件，跳空、涨跌停、暂停交易时不保证可成交或最大损失。

股票/场内 ETF：当次查证交易日、板块、涨跌幅限制、停复牌、申报单位、数量上下限、可卖份额、资金可用性及适用回转规则；不要硬编码所有标的都适用同一个 T+1 或整手规则。拟买金额不大于可用现金扣除现金底线、费用及其他待执行计划；卖出不大于可用数量。多笔方案按组合总预算核算，互斥方案明确标注，避免每笔重复占用同一现金。

场外基金：使用金额申购或份额赎回；核验开放日、截止时点、暂停/限购、最低金额、确认时间、赎回费及到账时间。官方净值、估算净值和未来成交净值不同，不能锁定未知成交价。赎回未到账资金不得同时用于买入；联动计划等待资金可用后再评估。

所有数值由已验证快照、当前规则和用户风险预算推导，列公式及舍入方法。限额缺失先列建议限额待用户确定，不能视为已授权。对同一计划 ID 的修订保留版本，不把“已确认计划”写成“已成交”。

确认具体计划后仍由用户在外部执行。只有真实成交回单或用户明确成交记录才交给持仓模块更新，保留成交时间、价格、数量、费用和来源；不从收盘价推定成交。本 Skill 不调用券商、不自动转账、不在无人值守任务中制造人工确认。
