# 15:30 数据交接

交接时间按北京时间。没有自动导出能力时，在同花顺 AI 复制下面的请求，再把其结果交给 NIA；平台无法访问的字段写“不可用”，不要用猜测补齐。

> 请根据你当前实际能读取且已获授权的数据，生成《NIA Invest OS 每日数据交接报告》。列北京时间、每项数据实际时间与来源。逐账户列持仓名称/代码/份额类别、数量/可用数量、成本、市值、浮盈亏、账户总现金与可用现金（后者包含于前者）、账户总资产；年度与累计收益分别列起止日和口径。真实成交列时间、方向、价格、数量、费用、净资金变化及成交编号；未成交委托另列。给出重要行情信号、重大风险事件、候选机会（标候选，非当前持仓）、有证据的纪律偏差和数据缺口。B/S 标记仅作交易点线索，明细不足不能补造成交。注明哪些读取、预警或导出能力本次确实可用；不要声称已与 NIA 自动连接。

NIA 接收后保存原摘要于私有目录，映射 `assets/handoff.template.json`；验证 Schema、数值、来源时间、账户完整性与重复项。交接报告建议顺序：时间/能力状态 → 账户与现金 → 成交 → 委托 → 信号/风险 → 候选 → 纪律 → 数据质量/待确认。

报告日期为当前日但数据可能是上次快照，必须同时保留。QDII/海外资产在北京时间 15:30 未必有当日正式净值；使用已披露时点并标延迟。非交易日不能编成交或盘中观察。

Schema 接受 partial/unavailable 数据用于说明缺口；这些状态不授权更新实时资产。manual_copy 只是传输方式，不能自动证明或否定真实性。verified_export 要有真实成功导出样本和能力证据；本项目不实现该接口。
