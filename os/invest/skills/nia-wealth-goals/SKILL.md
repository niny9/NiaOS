# 财富目标跟踪

读取私有目标文件和最近一次用户更正。目标按用户确认的口径计算；NIA 当前口径为全部净资产，包含房产等资产并扣除负债。个人目标金额不写入公开 Skill；按年保存 2026–2032 的已知目标，未知年份保持 null，不线性编造中间目标。年份明确但具体截止日未确定时，可将年末作为标明的测算假设，不能冒充已确认日期。

1. 建资产负债视图：投资账户、现金/储蓄、房产及其他资产、负债余额。使用统一估值日；房产注明估值来源、流动性与可变现折价，未上市权益不当作现金。家庭与个人资产所有权口径保持一致。未有完整资产/负债数据不能报告实际净资产或完成率。
2. 全部净资产=资产合计−负债；可投资资产、应急金与未来自由现金流另列。缺口=目标−当前同口径净资产，完成率=当前净资产/目标。区间目标分别计算上下沿，不能只挑容易达成的一端。
3. 拆分新增储蓄、事业收入净结余、资产回报、负债利息/偿还及大额支出，避免本金转移重复算财富增长。已包含在净资产里的现金不可再加一次。偿债若用已有现金偿还本金，净资产不凭空增加。
4. 给出不增长基线与用户指定的多个收益场景，注明收益、通胀、费用、税、储蓄与期限假设。回报只是情景，不是预期或承诺；不得把全部房产及现金统一套用股票收益率。
5. `scripts/goal_math.py` 仅用于单一资产池、月末等额净投入、固定名义年有效回报的情景公式；必须显式传入本金、目标、月数与回报。将投资池、房产和负债分别测算再聚合；不要把这个脚本用于有不规则现金流的实际 XIRR 或全家庭资产预测。
6. 收益要求过高时清楚呈现差距，优先讨论收入、储蓄、支出、目标区间或期限，不给“必达”策略。没有个人数据时列缺口清单和可验证计算方法，仍可完成目标文件整理。

每月或有大额变动时更新目标视图；每日简报复用最近有效版本并标日期。模板见 [goals.template.json](assets/goals.template.json)。
