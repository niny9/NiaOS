# Invest OS v1.8 集成清单

八项需求映射到三个升级模块和五个新模块，不机械复制同一实现。

| 用户能力名 | 实际 Skill 目录（相对 os/invest/skills） | 状态 |
|---|---|---|
| nia-invest-portfolio-manager | nia-wealth-holdings | 升级，多账户、历史/成交、现金与收益口径 |
| nia-invest-a-share-market-radar | nia-wealth-market-intelligence | 升级，A 股规则及开源框架证据 |
| nia-invest-trade-decision | nia-wealth-trade-plan | 升级，十字段、纪律与再配置 |
| nia-invest-opportunity-discovery | nia-invest-opportunity-discovery | 新增，六类比较及现金去向 |
| nia-invest-behavior-guardian | nia-invest-behavior-guardian | 新增，证据分级与个人纪律 |
| nia-invest-trade-journal | nia-invest-trade-journal | 新增，AI/真实成交独立日志 |
| nia-invest-strategy-evaluator | nia-invest-strategy-evaluator | 新增，交易日评测与版本审查 |
| nia-invest-tonghuashun-bridge | nia-invest-tonghuashun-bridge | 新增，手动/已验证导出交接协议 |

保留统一入口 invest-os、原七个 Wealth 模块及 Finance Quant、五类对账、中金财富六项；当前注册表 14 阶段、20 个阶段所有者/数据 Skill。本仓库自有 13 个 Skill（含入口）；旧八个外部 Skill 的可用性以 prepare 实际发现为准。

Schema 在 `invest-os/assets/schemas/`；各新增 Skill 的 `assets/` 放空白模板。AI/实际成交模板故意含 null，不能当有效记录追加。行为画像默认全 Unknown；交接模板为 unavailable，格式可读不表示接入成功。

统一执行规则：先 prepare 固定输入哈希，Agent 按依赖读 Skill 执行，写每阶段 receipt，check-results 验收，然后归档新日志/画像修订作为下一轮输入。Python 不代替研究 Agent、不运行券商、不创建定时任务。财务数据、私人目标、日志、运行回执不提交公共仓库。

验证命令（仓库根）：`python3 -m unittest discover -s os/invest/tests -p 'test_wealth_*.py' -v`。新增 JSON Schema 检查依赖 `jsonschema>=4.18,<5`；缺依赖明确失败，不默认通过。脚本校验可证结构与计算约束，不能证行情真实性或策略盈利。
