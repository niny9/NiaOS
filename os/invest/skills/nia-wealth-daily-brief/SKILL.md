# 每日投资报告

完整任务进入同级 [invest-os](../invest-os/SKILL.md)。已有 `orchestration_context=invest-os.stage` 时只汇总本 run 的产物，不重启流程。读 [环境接入](../invest-os/references/invocation.md)。不新增、复制、暂停或修改用户既有调度；安装成功不等于云端加载成功。

开头列北京时间、信息截止点、交易日状态、运行版本及数据可信度。依次包含九项：

1. 最新持仓与可信度：当前已核实、历史、用户转述、缺失分开。
2. 今日重要市场信息：事实、源时间与链接，观点与事实分开。
3. 现有股票/基金建议：触发、失效、不交易条件、风险与纪律；无依据允许持有/等待。
4. 新股票与基金机会：全部标“候选，非当前持仓”，附证据及比较。
5. 卖出资金下一步配置：可用和未到账分开，含继续持现金，不能重复占用。
6. 个人纪律提醒：证据等级、当前检查、历史错误是否有证据重现。
7. 昨日交易与 AI 信号复盘：分账；无成交不写实际收益，列 1/5/20 交易日到期评测。
8. 财富目标进度：逐项目标按金融资产/净资产/账户收益独立口径核对，缺基准不算百分比。
9. 待用户确认：影响结论的缺失信息及下一可验证条件。

盘前 08:00 用已完成交易日数据与新公告，不编当日行情。休市日复盘及下个交易日预案；日历未证实为 unknown。15:30 交接是另一报告模式，仍需环境实际触发。

缺数据可交付 degraded 报告，明确未完成阶段，不能因九段齐全就称实时系统运行。按 `本地日期 + report_type + 输入哈希` 去重并保留修订。先验收，再归档新 AI 信号，下一次重建工作单。只在已授权位置保存，不自行发外部消息或下单。
