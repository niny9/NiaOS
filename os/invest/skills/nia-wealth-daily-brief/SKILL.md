# 每日投资简报

复用用户已创建的每日自动任务。调用本 Skill 只执行本次研究与报告，不创建、不复制、不改动任何调度。安装 Skill 与未来自动任务成功执行是两项事实，需分别核验。

先读 [接入与输出](references/integration.md)，定位单一私有数据根及已有报告位置。依次使用同级 `nia-wealth-holdings` → `nia-wealth-market-intelligence` → `nia-wealth-portfolio-diagnosis` → `nia-wealth-risk` → `nia-wealth-trade-plan`，并读取 `nia-wealth-goals` 的最新目标视图。模块不可用时明确缺失，不将“可调用”写为“已运行”。可独立完成公开市场研究。

报告开头说明上海时间、信息截止点、交易状态和关键数据缺口，再按下列内容生成简报：

- 市场：与 A 股/基金及已知策略相关的重要事实、来源、变化与风险。
- 持仓：逐项结论、逻辑是否改变、反证和待查项；快照未确认则写“持仓诊断暂不可用”。
- 条件计划：优先级最高的至多三项动作，写触发/失效条件和人工复核点。补充持仓、核验数据、继续观察可以是动作；无依据时不凑三笔交易。
- 风险：仓位、集中度、现金、回撤，各指标的分母、日期及 unknown 项。
- 目标：全部净资产目标、最近核验的进度与缺口；净资产未知就不算完成率。每日只报告变化，不重新假定家庭估值。
- 下一步：待用户提供的数据、下一检查时间或可验证条件。

交易日前 08:00 等盘前运行以已完成交易日数据和最新公告为基准，不生成当日尚未发生的行情。休市日做复盘和下一交易日预案，交易日历未确认就标 unknown。只在本轮/自动任务明确授权的渠道交付；本 Skill 不自行向飞书、邮件或群聊发送。

以 `本地日期 + report_type + 输入版本哈希` 去重，修订保留前版引用。保存后回读确认路径、引用与状态；写入失败仍返回报告并标未归档。不要把报告生成说成成交完成。末尾可简短说明“供研究与人工决策参考，不自动下单”，不承诺收益。
