# 个人交易纪律

从 [行为画像模板](assets/behavior-profile.template.json) 开始。十类行为均默认 Unknown：追高、急涨后冲动买入、情绪化交易、亏损中反复补仓、无退出规则、不愿认亏拖延卖出、过早止盈、过度交易、年底回本压力下加风险、混用短线/波段/长期策略。

- Confirmed：真实成交明细与相应行情、原计划或用户明确陈述等证据充分支持。仅一张 B/S 图、一次亏损不能认定长期行为。
- Suspected：初步迹象，注明证据缺口与可推翻条件，不作为既定人格标签。
- Unknown：无证据。每次允许降级、修正或撤销标签，保留版本、反证及用户纠正。

同花顺 K 线 B/S 视为用户买卖点标记；仍须核对真实成交价格、股数、费用及动机。不能从涨跌或 B/S 猜测情绪，只有用户提供时记录情绪/动机；对动机类 Confirmed 必须有用户陈述。将行为判断与交易结果好坏分开。

对每项预案检查：策略期限、事前退出规则、触发是否仍成立、回撤/现金预算、是否因目标压力加码、是否重复历史行为。填写纪律结论 pass/warn/block/unknown、证据、针对个人的一句提醒和可观察的复核条件。无历史画像不妨碍检查本次规则，但不能宣称个人习惯已核实。warn/block/unknown 时数量金额保持 null，必要时建议等待和补证据。

结果交 `trade_plan`，其每项计划须再附最终纪律检查，避免预案改动后沿用旧结果。记录实际偏离只依据用户真实执行；不能为了安抚而抹去冲突，也不能把未经证实的心理推测写成事实。

运行统一入口的 `scripts/validate_record.py behavior PRIVATE_PROFILE` 检查标签证据。画像及原交易证据只写私有目录。
