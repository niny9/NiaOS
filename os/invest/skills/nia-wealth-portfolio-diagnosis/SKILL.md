# 持仓诊断

使用 `nia-wealth-holdings` 的已校验快照和 `nia-wealth-market-intelligence` 的带时间证据。未通过的持仓可列缺口和条件分析，不生成现有仓位百分比或断言应卖多少。

逐项检查：持有角色（核心/卫星/现金替代等来自用户策略）、成本与市值口径、原 thesis、最新支持证据、最强反证、催化剂、估值或业绩变化、流动性及下一验证日期。成本收益率不是未来投资价值；不因浮亏自动摊薄，也不因浮盈自动清仓。

A 股可复用 Invest OS 既有五类对账思路：管理层承诺、财报异常、反向验证、同行比较、长期行为。只有当前证据齐备时才调用既有引擎；先读代码确认无模拟输入、无通知或交易副作用。旧对账报告仅作历史，不沿用其中评分为当前结论。

ETF 核对跟踪指数、成分和集中度、费用、跟踪偏离/误差、折溢价、流动性。主动基金核对份额类别、经理变更、风格漂移、换手与费率；业绩对比保持同区间、同分红再投和同基准。不能仅按短期排名替换基金。

组合层检查证券/行业/风格暴露、股票与基金重叠、同一基金不同份额类别。穿透覆盖率=有可用底层披露的基金资产/基金总资产，注明报告期；未知部分不按零风险处理。既列直接暴露，也列估算穿透暴露，避免双重相加。

输出逐项 `thesis_status=intact/weakening/broken/unknown`、证据 ID、置信限制、候选动作 `review/observe/hold/reduce_candidate/increase_candidate`。这些是研究分类；转入 `nia-wealth-risk` 和 `nia-wealth-trade-plan` 后才形成有数量的条件计划。若没有新证据，“维持观察”是有效结果。
